How it works

For teachers

  1. Sign in with Google and create a class.
  2. Give the class the 6-character class code.
  3. Students sign in with the code, their name and their seat number. The roster fills in automatically, or you can bulk-import it first.
  4. Once the roster is final, tick Lock the roster so only listed seat numbers can sign in.

For students

  1. Your seat number is your account. Sign in with the same code and seat number on any device and you will see exactly the same work.
  2. There is no password, so please never sign in with someone else's seat number.
